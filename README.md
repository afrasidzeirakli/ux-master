# UX MASTER — Claude Skill

A Claude skill that designs, audits, reviews and restyles screens and components with senior UX/UI rules, so the result never looks AI-made: dashboards, forms, tables, modals, mobile and dark mode.

## Install

**Claude (web or desktop):** download the `ux-master` folder, compress it into a ZIP file and upload it in **Customize > Skills**.

**Claude Code:** copy the `ux-master` folder into `~/.claude/skills/`.

```bash
git clone https://github.com/afrasidzeirakli/ux-master.git
cp -r ux-master/ux-master ~/.claude/skills/
```

## What's inside

- `ux-master/SKILL.md` — the full skill: working modes (design, audit, review, restyle), rules by topic, a design system blueprint, how to kill the AI look, and a final check before delivering.
